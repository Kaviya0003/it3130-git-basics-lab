\# IT3130 Git Basics Lab



\## Purpose



This repository demonstrates a basic Git workflow for IT3130.



\## Files



\* HelloWorld.html - a small web page used to practise version control

\* README.md - project documentation



\## Commands practised



git init, git status, git add, git diff, git commit, git log, git remote, git push



\## What I learned



I learned that changes are first made in the working directory and then added to the staging area before creating a commit. I also learned that commits save changes in the local repository, while remotes allow the committed changes to be shared with a GitHub repository.
