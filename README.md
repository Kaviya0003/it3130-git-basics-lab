&#x20;# IT3130 Git Basics Lab



\## Purpose

This repository demonstrates a basic Git workflow for IT3130.



\## Files

\- HelloWorld.html - a small web page used to practise version control

\- README.md - project documentation



\## Commands practised

git init, git status, git add, git diff, git commit, git log, git remote, git push



\## What I learned

I learned how Git tracks changes using the working directory, staging area, and local repository. I also learned how to create commits and connect a local repository to a remote GitHub repository. The remote repository allows the project to be pushed to GitHub and shared or backed up online.
